# Phase 1 Data Model: macOS Packaging & Release

No runtime entities. The "data" here is build configuration and generated artifacts.

---

## Artifacts produced by one `npm run dist`

| File (in `release/`) | What |
|---|---|
| `HyppoVisor-<version>-arm64.dmg` | Apple Silicon app, disk image |
| `HyppoVisor-<version>-arm64-mac.zip` | Apple Silicon app, archive (same bundle as the dmg) |
| `HyppoVisor-<version>-x64.dmg` | Intel app, disk image |
| `HyppoVisor-<version>-x64-mac.zip` | Intel app, archive (same bundle as the dmg) |
| `latest-mac.yml`, `*.blockmap` | electron-builder metadata (harmless; not part of the contract) |

`<version>` = `package.json` `version` verbatim (pre-1.0 / pre-release strings allowed).
Each `.app` contains, in `Contents/Resources/`: `LICENSE`, `NOTICE`, `THIRD-PARTY-LICENSES`.

---

## Generated file: `./THIRD-PARTY-LICENSES`

- Regenerated every `npm run dist` (git-ignored).
- Structure: a fixed header, then one section per **production** dependency, **sorted by
  package name**:
  ```
  ## <name>@<version>
  License: <SPDX id>
  Repository: <url>

  <full license text>
  ```
- Deterministic: identical `node_modules` ⇒ byte-identical file (SC-006).
- Coverage: 100% of the `dependencies` closure that `electron-builder` bundles into
  `app.asar` (SC-004), plus an ffmpeg / Electron-runtime entry.

---

## Permissive-license allowlist (`scripts/check-licenses.js`)

A fixed array. A bundled production dependency whose normalized SPDX id is **not** in this
list — or is `UNKNOWN` / absent / an unparseable expression — fails the build (exit 1,
naming the package).

```
MIT  MIT-0  ISC  0BSD  BSD-2-Clause  BSD-3-Clause  Apache-2.0
BlueOak-1.0.0  CC0-1.0  CC-BY-4.0  Unlicense  Python-2.0  WTFPL
```

**Special case**: the Electron runtime's `libffmpeg.dylib` (LGPL-2.1-or-later) is permitted
by exact identity — a dynamically-linked, replaceable system library is the constitution's
explicit carve-out. LGPL is **not** added to the general allowlist; only this one known
entry is whitelisted by name, and `PACKAGING.md` records the replace/relink path.

## `electron-builder.yml` — the keys that matter

| Key | Value | Why |
|---|---|---|
| `appId` | `com.juliaviluhina.hyppovisor` | macOS bundle id |
| `productName` | `HyppoVisor` | `.app` name |
| `directories.output` | `release` | git-ignored; avoids the `dist/` (tsc output) collision |
| `directories.buildResources` | `build` | electron-builder reads `build/icon.png` → generates `.icns` |
| `files` | `dist/**`, `package.json`, `!**/*.map` | what goes in `app.asar` |
| `mac.target` | `dmg` + `zip`, each `arch: [arm64, x64]` | four artifacts (clarify decision) |
| `mac.artifactName` | `${productName}-${version}-${arch}.${ext}` | version + arch in every filename |
| `extraResources` | `LICENSE`, `NOTICE`, `THIRD-PARTY-LICENSES` | ship inside the bundle |
| `electronDist` | `node_modules/electron/dist` | no network fetch during packaging (FR-004) |
| *(deferred)* `mac.identity`, `mac.notarize` | unset | signing is a follow-up |

## `package.json` deltas

- `devDependencies`: `+ electron-builder`, `+ license-checker-rseidelsohn`.
- `scripts`: `+ dist`, `+ licenses:check`, `+ licenses:gen` (see `research.md` R2).
- `version` is the single source for the artifact version — unchanged mechanism.

## `.gitignore` deltas

`+ release/`  ·  `+ THIRD-PARTY-LICENSES`

## Deleted (tracked) files

`build/icon.icns`, `build/icon.iconset/` — regenerated by `electron-builder` from
`build/icon.png` at package time (verified once before deletion).

## Modified (tracked) files — bytes only

`build/icon.png`, `assets/hyppovisor.png`, `src/renderer/mascot.png`,
`src/renderer/hyppo.png` — losslessly re-compressed, visually identical.
